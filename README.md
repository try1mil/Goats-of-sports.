# Goats-of-sports.
Fan page of my favorite athletes. The navigation is simple. You start in the "Goats" starting page by choosing which athlete you want to know more about, you then get to chose between four options : who are they, their records, how good were they, timeline of their career. 
The atheltes are :
Lionel Messi (Football)
Alexandra Trusova (Figureskating)
Micheal Schumacher (Formula 1)
Svetlana Khorkina (Gymnastics)

no AI was used in the making of this project.
